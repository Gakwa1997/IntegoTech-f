# IntegoTech — Digital Transformation Consultancy

Single-page website positioning IntegoTech as a digital transformation consultancy:
websites and platforms, custom management systems, and cloud infrastructure —
delivered on site or entirely remotely.

## Files

| File | Purpose |
|---|---|
| `index.html` | The entire website — HTML, CSS and JS in one file, no dependencies |
| `BRAND-STRATEGY.md` | Positioning rationale, 3 tagline options, copy strategy, trust signals |
| `logos/` | Drop real client logo images here (see `logos/README.txt`) |
| `.nojekyll` | Stops GitHub Pages from processing the files |

8. **Support Partnerships** — Essential · Managed Partner · Strategic Partner
9. **About** — named authority, credentials, skills
10. **FAQ** — six real objections
11. **Contact** — strategy consultation booking

## Publish to GitHub Pages

1. **github.com** → **+** → **New repository** → name it `integotech` → **Public** → **Create**
2. Click **uploading an existing file**
3. Unzip this folder and drag in **everything inside it** (including hidden `.nojekyll`)
4. Commit the changes
5. **Settings → Pages** → Source: **Deploy from a branch** → `main` + `/ (root)` → **Save**
6. Wait ~2 minutes, then refresh — your live URL appears at the top

Live at `https://YOURUSERNAME.github.io/integotech/`

> If hidden files don't appear when dragging, press `Ctrl+H` (Windows) or `Cmd+Shift+.` (Mac).

## Editing

Open `index.html` in any text editor and search for the tag:

| Search for | Changes |
|---|---|
| `EDIT: COLOURS` | Whole colour palette — one `:root` block |
| `EDIT: MOTTO` | The tagline, in both places |
| `EDIT: BRAND` | Company name and logo mark |
| `EDIT: CONTACT` | Phone, email, hours, WhatsApp |
| `EDIT: PACKAGES` | The three support partnerships |
| `EDIT: PARTNERS` | Client logo strip |
| `EDIT: PROFILE` | CV, experience and skill chips |
